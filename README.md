# gamestore-core

Ядро магазина цифровых товаров для геймеров: заказы по SKU, платёжные вебхуки,
автоматическая выдача кодов через поставщиков, сверка и денежный журнал.

Тестовое задание. Акцент — не на объёме функций, а на надёжности денежного пути:
однократная выдача под гонками, корректная обработка таймаута поставщика, восстановление
после сбоев.

> **Статус:** в разработке. Готово: Ш0 (окружение), Ш1 (схема данных и инварианты в БД),
> Ш2 (ядро API: заказы, вебхук оплаты, автовыдача из пула). 115 тестов, PHPStan level 9
> без подавлений.
> План этапов — [docs/PLAN.md](docs/PLAN.md), обязательные правила кода — [CLAUDE.md](CLAUDE.md).

## Быстрый старт

```bash
git clone <repo> gamestore-core && cd gamestore-core
make up          # поднимет app:8000, postgres:5434, redis:6381, воркеры, шедулер
make fresh       # схема + сид: 12 SKU и 50 ключей из задания
make demo        # сквозной сценарий: заказ → вебхук оплаты → выдача кода
```

Без Docker (на машине нужен PHP 8.3 c `pdo_pgsql`/`redis`, PostgreSQL 16, Redis):

```bash
composer install
cp .env.example .env && php artisan key:generate
php artisan migrate --seed
php artisan serve --port=8000
```


## Стек и почему он такой

| | | |
|---|---|---|
| PHP 8.3 | `declare(strict_types=1)` везде | Pest 5 / PHPUnit 13 требуют 8.4 |
| Laravel 12 | | зрелая связка с larastan 3 |
| PostgreSQL 16 | `SKIP LOCKED`, partial unique, advisory-локи, отложенные constraint-триггеры | это несущие элементы схемы, а не оптимизация |
| Redis | очереди и circuit breaker | очереди `payments` и `delivery` разделены |
| PHPStan **level 9** | `ignoreErrors: []`, baseline запрещён | «PHPStan 9» из задания = уровень 9 |
| PHPUnit 11 | отдельный набор `Race` | гонки гоняются на реальной БД без обёрточной транзакции |

Порты нестандартные (8000 / 5434 / 6381), потому что 5432, 6379 и 8080 на машине разработки
заняты другими проектами.

## API

| Метод | Путь | Комментарий |
|---|---|---|
| `POST` | `/api/v1/orders` | Заголовок `Idempotency-Key` обязателен; без него 422 |
| `GET` | `/api/v1/orders/{public_id}` | Та же форма ответа, что у создания |
| `POST` | `/api/v1/webhooks/payment` | Всегда 200 на осмысленный JSON; без троттлинга |

```bash
# создать заказ
curl -X POST localhost:8000/api/v1/orders \
  -H 'Content-Type: application/json' -H 'Idempotency-Key: my-key-1' \
  -d '{"sku":"KEY-CS2-PRIME"}'

# оплатить (эмулятор платёжной системы, он же инструмент проверки гонок)
php artisan shop:webhook ord_00001

# посмотреть заказ
curl localhost:8000/api/v1/orders/ord_00001
```
